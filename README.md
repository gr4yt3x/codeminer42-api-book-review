📚 Codeminer42 API Books-User-Reviews

Este projeto foi desenvolvido em Ruby com base no seguinte desafio:

"A biblioteca precisa de um sistema para gerenciar seus usuários, livros e avaliações.
Deve ser possível consultar todos os usuários (em ordem alfabética), ver os dados de um usuário específico, listar o acervo de livros com opção de filtro por ano de publicação, consultar detalhes de um título, adicionar novos livros, atualizar informações existentes e remover obras do catálogo quando necessário.
Também é possível visualizar as avaliações feitas — tanto no geral quanto por livro ou por usuário."


🧰 Tecnologias Utilizadas

- Sinatra — framework web minimalista para Ruby
- ActiveRecord — ORM para manipulação do banco de dados
- SQLite — banco de dados leve e simples para desenvolvimento local
- RSpec — framework de testes para Ruby
